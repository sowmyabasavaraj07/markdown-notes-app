# Markdown Notes App

A simple web app built with Python and Flask where users can write and save notes using Markdown formatting.

## Features

- Create notes
- Edit notes
- Delete notes
- Preview notes with Markdown formatting

## Tech stack

- Python 3
- Flask
- Markdown library
- HTML and CSS

## How to run

1. Install the requirements:

```
pip install flask markdown
```

2. Start the app:

```
python -m flask --app app run
```

3. Open `http://127.0.0.1:5000` in your browser.

## Project structure

```
app.py            Flask routes and note storage
templates/        HTML pages
notes.json        Saved notes (created automatically)
```
